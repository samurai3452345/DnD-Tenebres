# Новое оружие

23 новых шаблона добавлены в общий справочник `012-populate-weapons.xml` через `<insert>`.
Характеристики подобраны по существующим аналогам; новых пассивных эффектов нет.
Все предметы занимают `MAIN_HAND`, парное оружие — один предмет с двумя кубиками урона.
Требуемый уровень — 1, базовая прочность — 100, как у существующих шаблонов оружия.

Урон ниже — **базовые кубики**, без модификаторов характеристик, редкости и улучшения.
Бонус от редкости уже рассчитывается боевой системой: необычная +1, редкая +2, эпическая +4, легендарная +6.

Добыча, магазины и рецепты получения нового оружия пока не настроены.
Предметы можно выдавать через существующий `InventoryService.addItemToPlayer` по точному имени шаблона.
Новые иконки не добавлены: для этих 23 предметов отдельные изображения ещё не предоставлены.
После применения миграции характеристики изменять новой миграцией, не редактированием уже применённой.
