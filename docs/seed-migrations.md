# Заполнение справочников

Данные справочников задаются через Liquibase `<insert>` с отдельными `<column>`.
Оружие собрано в `012-populate-weapons.xml`, ресурсы, руда и припасы — в
`014-populate-resources.xml`. Отдельные файлы `026`, `046`, `047`, `048` объединены
с этими справочниками и больше не подключаются.

Ссылки на автоматически назначаемые ID разрешаются по имени через
`valueComputed="(SELECT ...)"`. Ограничения, индексы и обновление существующих
данных по-прежнему могут использовать `<sql>`; это не заполнение справочников.

История миграций переписана для локальной разработки. Уже созданную локальную
БД нужно пересоздать перед запуском: контрольные суммы и порядок ID изменились.
Очистка контрольных сумм сама по себе не заменяет пересоздание БД. Для сохранения
данных в развернутой БД потребуется отдельная стратегия обновления.
